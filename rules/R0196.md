Name a file you generate `<descriptor>-<timestamp>`, the timestamp taken at generation time in ISO 8601 basic format, UTC, with the `Z` designator and both date and time components present: `<YYYYMMDD>T<HHMMSS>Z`. Where a stated convention names the file, follow that convention instead.

## Human

Ruled by DEC-000290: repo-wide, a generated timestamp is ISO 8601 basic format, UTC, with the `Z` designator required and date and time components both present. The ruling settles the C019 divergence, in which Core required only the basic format, directive authoring added that both components be present, and the retro skill added UTC and the `Z` — so a filename satisfying Core's rule failed the retro skill's.
