Name a file you generate `<descriptor>-<timestamp>`, the timestamp taken at generation time in ISO 8601 basic format, UTC, with the `Z` designator and both date and time components present: `<YYYYMMDD>T<HHMMSS>Z`. Where a stated convention names the file, follow that convention instead.

```yaml
event: PostToolUse
matcher: Edit|Write
command: bin/hooks/store-lint --check generated-filename
```

## Human

Ruled by DEC-000290: repo-wide, a generated timestamp is ISO 8601 basic format, UTC, with the `Z` designator required and date and time components both present. The hook matches the tool call, not intent: it fails a new file under `retros/` or `reviews/` whose name lacks the timestamp, and nothing else.
