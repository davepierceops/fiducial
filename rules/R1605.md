A row cites another row only by its ID in square brackets, and only where every value the citing row carries on role, session, and corpus the cited row carries too, so the cited row renders in every bundle the citing one does.

```yaml
event: PostToolUse
matcher: Edit|Write
command: bin/hooks/store-lint --check citations
# store-lint also carries R0264's four criteria (DEC-001380): a row refers to no
# file by path; every key value is one the key already holds; the row names the
# session kind it binds; it speaks in tiers, never model names.
```

## Human

The hook matches the tool call, not intent: it fails a write under `rules/` whose citation cannot co-render, and nothing else.
