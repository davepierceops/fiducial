For a routine change, open a pull request and merge it. No human gate fires at the merge; the gate is the release decision.

## Human

The merge is not a gate. Every pull request still gets a code review by an agent, without exception, per process/change-flow.md's Quality dimension; what does not fire at the merge is a human gate.
