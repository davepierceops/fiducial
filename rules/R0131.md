term: [mock-verified]

Mock-verified evidence supports application logic, parsing, error handling, UI state, edge cases, retry behavior, and fast local feedback. It proves nothing about third-party auth, live availability, live schema stability, browser-only behavior, deployment config, quota or billing state, or CORS and domain rules.
