Never let a secret value enter context. Reference that a secret exists and where it lives instead.

```yaml
deny:
  - Read(./.env)
  - Read(./.env.*)
  - Read(./**/.env)
  - Read(./**/.env.*)
  - Read(./**/secrets/**)
  - Read(~/.aws/**)
  - Read(~/.ssh/**)
  - Bash(printenv*)
  - Bash(cat *.env*)
  - Bash(cat ~/.aws/*)
  - Bash(cat ~/.ssh/*)
```

## Human

A deny matches tool calls, not intent: it refuses the reads and shell commands the patterns name, and a secret reached any other way is still this row's principle, carried into `CLAUDE.md`.
