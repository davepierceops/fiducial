A change that writes an entity's primary fields — create, edit, merge, import — also accounts for that entity's derived fields, the values computed from primary fields rather than supplied directly.

## Human

A derived field is not "content" the way a primary field is, so the Coder and an independent Test Designer can both omit it — from the implementation and from the test plan — and share the blind spot.
