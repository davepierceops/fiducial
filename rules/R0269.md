Check that what you review carries at least one key that selects it into a bundle, every value taken from the values that key already holds, and an `order` wherever it must be read before something else in the same bundle.

## Human

The rubric said `audience:` and a known value set. Under DEC-000400 selection is a query over keys and intake normalizes every incoming key against the keys already in use, so the criterion tests the selector keys rather than one named field.
