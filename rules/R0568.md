Protect the default branch in the forge's configuration: no force-push, no branch deletion, changes landing only through a pull request, and no bypass, including for administrators.

## Human

Server-side protection binds every credential that reaches the repository, including ones no local configuration has ever seen, and the last requirement — no bypass — carries the others. It is stated as an adoption precondition because nothing inside the repository can verify it.
