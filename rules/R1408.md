Never rewrite an existing review artifact to match a later version of this schema; the schema binds artifacts written after it lands.

```yaml
event: PreToolUse
matcher: Edit|Write
command: bin/hooks/review-artifact-immutable
# refuses writes to reviews/ files on origin/main or main; unlanded branch drafts pass
# with neither default-branch ref present, falls back to tracked-at-HEAD protection
```

## Human

An artifact is the review record of a document already approved. Rewriting a record of what happened to match a later format is the drift this repo exists to prevent. The hook matches the tool call, not intent: it refuses a write to a file under `reviews/` present on `origin/main` or `main`; a draft not on either ref may be amended, whether committed on the working branch or untracked. With neither default-branch ref present, the hook falls back to tracked-at-HEAD protection. This is a hook rather than a path deny (DEC-001230); DEC-001640 ratifies the default-branch observable.
