Never rewrite an existing review artifact to match a later version of this schema; the schema binds artifacts written after it lands.

```yaml
event: PreToolUse
matcher: Edit|Write
command: bin/hooks/review-artifact-immutable
```

## Human

An artifact is the review record of a document already approved. Rewriting a record of what happened to match a later format is the drift this repo exists to prevent. The hook matches the tool call, not intent: it refuses a write to a file that already exists under `reviews/`, which is why this is a hook and not a path deny (DEC-001230).
