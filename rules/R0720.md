The repository's log is the record of what landed. After any remote write, read it back from the fetched remote before reporting — that it landed, and that what landed is what you sent (size, commit stats). State only SHAs you read from the log.

## Human

A tool's response is a claim about a write, not evidence of one. The case this catches: a call carrying a placeholder string as its content parameter replaced a ~64KB file on the default branch with 19 bytes; the response was success-shaped, the commit was real, and only the size disagreed with expectation.
