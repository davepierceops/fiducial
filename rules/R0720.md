## Human

The hook matches the tool call, not intent: after a `git push` it fetches the remote and prints the ref's SHA, failing loudly if it differs from what was sent; citing that evidence is R0172's obligation. The case behind it: a call carrying a placeholder string as its content parameter replaced a ~64KB file on the default branch with 19 bytes; the response was success-shaped, the commit was real, and only the size disagreed with expectation.
