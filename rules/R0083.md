A red-gate is a test run that fails on wrong behavior. A run that fails only because the module under test does not exist yet is not one.

## Human

A wrong assertion fails on a missing module exactly as a right one does, so a missing-module red proves nothing about the assertions. It also defeats the Test Designer / Coder separation: both agents can hold the same blind spot, and the blind spot survives to green.
