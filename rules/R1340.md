term: [eligible line, eligible lines]

A line is eligible unless it is masked. Fenced code blocks mask — a backtick or tilde run of three or more of the same character, opened at column 0 or indented up to three spaces and closed by a run of at least the opening length, the fence lines themselves masked, an unclosed fence masking to end of file — as do blockquote lines and HTML comments from the line containing `<!--` through the line containing `-->`. Indented code blocks do not mask. Line endings are normalised before masking, and the match is byte-exact thereafter.
