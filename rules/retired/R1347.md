A marker is a line at column 0 that is either an ATX heading — one to six `#` characters, a space, then text, the token being the text after the run — or an all-caps run of three or more characters drawn from `A`-`Z`, `0`-`9`, `-` and single interior spaces, terminated by any character outside that set or by end of line, the token being the run. Nothing else is a marker.
