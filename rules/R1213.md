Where a human must relay output between blocks, send one block per turn: wait for the output, then compose the next.

## Human

A second block written before the first has run is written against a guess at its output — batching commits to an untested assumption and hides that it did so. This binds blocks handed to a human intermediary; it does not bind a sequence an agent runs itself with no one in the loop.
