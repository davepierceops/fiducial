An open spec delta is the interval in which a spec's branch carries commits the default branch does not; it ends when the spec closes at agreement. A revision of an agreed spec opens a new delta on a new branch.

## Human

Restated in the open/closed vocabulary of process/change-flow.md, which retires the `converging` status and the definition of converging as an interval distinct from a delta (DEC-000380). What survives is the delta itself: a spec branch is open or closed, and there is no third state to tell it apart from.
