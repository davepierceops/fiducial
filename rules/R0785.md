Common boundary types are mocked HTTP APIs, browser APIs, storage, authentication, authorization, time, geolocation, service workers, network state and map or tile providers; local fixtures representing third-party data; generated data standing in for production data; a headless DOM replacing a real browser; and local development config or environment variables replacing deployed production config and secrets.

## Human

The boundary types name the representation mechanisms that stand in for production; the boundary-sensitive areas named in the testing and verification rules name where a claim is easy to overstate — complementary cuts, not competing taxonomies.
