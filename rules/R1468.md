Write tests against an open spec branch and nothing else: the Test Designer starts once the entry read over the spec as it stands has run and Dave has said to proceed, and runs the red gate while the branch is open so its result is the close's evidence. Implement nothing against an open spec, and run no per-change stage against one.

## Human

DEC-000360 ruled that spec and tests converge before agreement as the standard flow, and that building against a spec is three-valued — nothing while it is drafted, tests only while it is open, implementation once it is closed. Its mechanism, the `converging` status and its frontmatter transitions, is retired by DEC-000380 and by process/change-flow.md; its three substantive values are kept here in open/closed vocabulary. This row settles the C017 and C024 divergence, in which the metadata policy barred testing against the same document the operating model and this skill required tests for.
