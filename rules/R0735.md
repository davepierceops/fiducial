Report a write whose size or commit stats disagree with expectation as a failed write, whatever the response said.

## Human

The case this catches: a call carrying a placeholder string as its content parameter replaced a ~64KB file on the default branch with 19 bytes. The response was success-shaped, the commit was real, and only the `size` field disagreed with expectation.
