A directive is the package handed to an execution session: one line stating route (fresh or existing session) and model tier, stated in full every time, then the execution block. The executor's first act is to write it to a file, commit it alone, push, and report the SHA; from then on it is cited by path and SHA. An instruction is one direction in it, individually refusable. A companion document is a committed file the directive requires the executor to read first, cited by its own path and SHA.
