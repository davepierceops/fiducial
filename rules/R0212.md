Make the execution block's first instruction this: write the directive verbatim to the named path, commit it alone with a message naming the package it opens, push the branch to origin, and report the SHA — before reading anything else and before touching any other file. Thereafter cite the directive by its path and the SHA of the commit that landed it, capture that path and SHA first in any record, and ask for them where a report omits them.
