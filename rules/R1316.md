The exclusive-assignment disposition is written as the label, the parenthetical `(exclusive assignment)`, the worktree path in quotes, and the `git worktree add` command that creates it — worked: `WORKING-TREE DISPOSITION (exclusive assignment): this session works only in a worktree at "wt/<name>", created by: git worktree add --no-track "wt/<name>" -b <name> origin/main`.
