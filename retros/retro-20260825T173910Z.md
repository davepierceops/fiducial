## Interpretation

- (E1) A derived table column written per-row without a stated rule is a
  defect generator, not a set of independent defects. Repairing instances
  leaves the generator; stating the generative rule once removes it and
  retires the class.
- (E2, E3) A directive that states normative precedence plus
  surface-don't-resolve gives the executor a decidable boundary: mechanical
  consequences of the precedence get fixed, genuine judgment gets escalated.
  The four-seam report split exactly on that line, which is the behaviour the
  clause exists to produce.
- (E2, E3) Act-then-flag on a cheap-to-reverse extension beat stall-and-ask:
  the FM-11 cell was correct under the normative sections, and the flag cost
  one confirm turn instead of a mid-execution stop.
- (E4) Naming sweep targets converts Core rule 13 from an aspiration into a
  checklist; the named target was the load-bearing catch (a test criterion
  that would have shipped asserting the wrong shape).
- (E5) Pre-staging a recommendation inside a batched disposition lets one
  confirm cover a real judgment call — consistent with the standing
  pre-stage principle, extended here to intra-batch decisions.

## Durable insights

- When a reviewer diagnoses a defect class alongside its instances, triage
  the class first and check whether one structural fix discharges the
  instances. Surface that option before disposing findings separately.
- Reusable directive clause for any rewrite deriving a table or summary from
  normative sections: name the normative sections, state they win over the
  derived text, and instruct surface-don't-resolve on disagreement.
- In batched dispositions, state a recommendation inline for any
  reviewer-left-open selection, so a single confirm covers it.
