## Interpretation

- (1, 7) The walk format — one topic per turn, what-it-is before the choice,
  y/n — carried 33 rulings in one session, but reports interleaved with the
  walk repeatedly displaced the open question; the restate-after-reports rule
  Dave ratified mid-walk (T16) is aimed at exactly the failure this session
  kept producing.
- (3, 5) Both authoring defects were recall-where-reading-was-owed: a git
  flag from memory, a tool's commit behaviour from assumption. The fix that
  worked both times was mechanical verification before dispatch — dry-run in
  the sandbox, lint, re-read the prior directive of the same class.
- (4) A lint that is trusted needs its false positives triaged like findings:
  both M2 cases were classified (tool defect, not directive defect) and
  ridered rather than worked around, which kept the lint's authority intact.
- (6) Carrying reviewer Fix wording verbatim measurably shortened
  convergence; the two second-round findings were both in *dictated* wording,
  which supports the T02 rule that dictation is what the author must check
  hardest.
- (9) Pre-ruling dispositions into a read-only pass inverted the evidence
  order: the reviewer holding the tree was overridden by the decision session
  holding a memory. Keep-and-flag limited the damage to one triage line.
- (10) A preference that resurfaces three times before being ruled is the
  T17 pattern even when each instance looks settled; the same-turn encoding
  rule now exists because this session finally hit it hard enough.

## Durable insights

- Lint-then-dry-run before every handover is now standard and caught real
  defects every time it ran; nothing freehand survives contact.
- The reuse worktree form is settled and worded: plain `git worktree add
  "<path>" <branch>`, no `-b`, no `--no-track`.
- A confirmation gate scoped to named resolutions converges in one round
  when fixes carry reviewer wording verbatim.
- The amendment-to-the-same-session pattern (supersede one instruction,
  everything else stands) recovers a correct stop in one turn.

- Everything else surfaced today was ruled and flushed the same day
  (OPEN-ITEMS "Topic walk 2026-08-31 — rulings"); restating it here would be
