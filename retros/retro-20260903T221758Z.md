## Durable insights

- **Probe the hook before pricing a package.** Whether an edit flips status is
  a one-command observation; the answer changes the return path from
  N cycles to zero.
- **Dictated anchor/replacement edits are a reliable transport** for
  decision-session changes that must go through an executor: five edits,
  exact anchors, one occurrence each, stop on zero-or-many — reproduced
  byte-for-byte against the dry run.
- **Read PR state through a different tool than the one that timed out.**
  A connector read after a connector write timeout is itself likely to hang;
  REST rate-limits after two calls. The confirmed pattern is: reconnect, one
  connector list read, then re-issue.
- **A directive's expected count is a report field, not a stop condition** —
  restated from session 2, and again correct twice this session (9).
