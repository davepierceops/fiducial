## DL-1 — non-blocking
Claim: Rule 13's trigger sentence lost the clause naming the receiver, so it now reads as owing a baton at any session end that hands responsibility onward, including a hand-off to an execution session, which Core says a baton never is.
Location: docs/global-context/decision-layer.md:32 (rule 13, last sentence, "Every session end that hands responsibility onward emits one."), against docs/global-context/core.md:54 (Handoff — "transfer of unfinished responsibility between sessions or roles … handing a directive to an execution session is one mechanism by which a handoff is carried out") and core.md:55 (Baton — "A baton passes between decision sessions only; a directive hands work to an execution session. The two never blur.")
Evidence: Verified by running. `git diff 275f84c 3e89a21 -- docs/global-context/decision-layer.md` shows the prior sentence "Every session end that hands responsibility to a successor decision session emits one." compressed to the current form; the receiver clause is the only content that sentence lost. The topic-walk ruling at docs/cycles/topic-walk-flush-20260831T210000Z.md:46-50 rules the baton's contents — pointers-only, one carve-out labelled told — and says nothing about its trigger, so the compression, not a ruling, produced the change. "Responsibility" is the word Core's Handoff entry uses for both mechanisms, so the rule as written covers both. Criterion 12 — the rule states the baton's occasion differently from Core's definition of it.
Consequence: A decision session that ends by handing a directive to an execution session, with no successor decision session, reads rule 13 as owing a baton and either emits one to no receiver or resolves the ambiguity from Core's Vocabulary. Under core.md:10 the definition at core.md:55 wins, so the effect is a spurious baton or a moment of inference, not a lost handoff — which is why this is non-blocking rather than blocking.
Fix: Restore the receiver in the rule's own idiom: "Every session end that hands responsibility to a successor decision session emits one." Five words back; the sentence stays under the compressed budget.
