## F1 — non-blocking
Claim: R1039 still requires the release manager to confirm the `human-gate` issue is open and linked before presenting a consequential change, which conflicts with the new fallback where the issue cannot be opened and the human's go in chat releases the change.
Classification: defect
Location: rules/R1039.md body; process/gate.md:17-18 (step 2) against gate.md:20-24 (step 4)
Evidence: Inferred by reading. R1039 (release-manager-agent, `condition: the change is consequential`) is unconditional on tracker reachability. The release-manager bundle receives both R1039 and the gate skill, and the new step 4 tells it to present the derived body in place of the pointer. DEC-001820 says "Where the tracker is reachable, the gate issue is opened and linked before the request as now", which scopes R1039's behaviour to the reachable case only. #446 acceptance: "no other rule or process document still states the old behaviour." Under the old text, step 4 already presented the body, so part of the tension predates this delta. The new release path makes it material. Criterion: R0264 "Agree with existing rules; flag conflicts for human resolution."
Consequence: A release-manager agent with the tracker down obeys R1039, refuses to present the change, and the DEC-001820 fallback cannot be reached from that role. Alternatively it treats the two rows as contradictory and stalls.
Fix: Bring to the human. Recommended: condition R1039 (and gate.md step 2) on "where the `human-gate` issue can be opened", consistent with DEC-001820's "as now" clause. This would land in this intake or a follow-up.

## F2 — non-blocking
Claim: The skeleton heading `### Production SLOs (optional)` sits unconditionally in the spec skeleton, so a spec drafted by copying the skeleton gets the heading whose presence is now the single trigger for every SLO obligation.
Classification: defect
Location: process/spec-template.md:80
Evidence: Inferred by reading. The template prose at :45-49 says the subsection is "present only when the project runs a monitored production system" and that "its presence is the trigger". Rows test for "a Production SLOs subsection". The skeleton is the copy-paste form. Criterion: R1621 (clarity and safety as LLM context).
Consequence: A non-production project that copies the skeleton fires the SLO and error-budget obligations of R0863, R1107, R1143, R0129, R0502, R1032, R1041, R1183 and checklist line 31. This is the invented-target outcome DEC-001870 was ruled to stop.
Fix: Take the heading out of the skeleton and keep it in prose, or annotate it in the skeleton as "omit unless the project runs a monitored production system". Either way, state that an absent heading, not an empty or N/A one, is the off state.
