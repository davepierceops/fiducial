## B1 — blocking
Claim: AC-CO-1 has a second filename branch — `--name SLUG` writes `docs/cycles/<SLUG>-directive.md` — which is a third form that M8 rejects and that AC-DT-06 names as a fixture required to exit non-zero, so the contract this cycle re-affirms as preserved intact obliges the generator to emit a filename its own lint refuses.
Location: specs/directive-tooling.md §4 M8 row and the "M8 admits two forms" paragraph; §4 "Mode scoping"; §6 AC-DT-06 (M8 clause), AC-DT-15; docs/packages/package-a-spec.md §3.6 AC-CO-1; bin/tests/test_cycle_open.py:76.
Evidence: Verified by reading and by running. AC-CO-1 reads, whole: "Writes `docs/cycles/cycle-<N>-directive.md` for `--cycle N`, or `docs/cycles/<SLUG>-directive.md` for `--name SLUG`; exactly one of the two is required (exit 2)." The revised §4 quotes only the first half — "AC-CO-1 requires `bin/cycle-open` to write `docs/cycles/cycle-<N>-directive.md` for `--cycle N`" — and the omission is what has kept the second branch out of view for two cycles. `bin/cycle-open:66-67` implements it (`return "docs/cycles/%s-directive.md" % args.name`), `bin/tests/test_cycle_open.py:76` asserts it under the heading `AC-CO-1: --name SLUG writes docs/cycles/<SLUG>-directive.md`, and that suite is green: 31 tests, exit 0, run this cycle. AC-DT-15 requires it to stay green with none of the twelve retired. Against that, AC-DT-06's M8 clause requires "a fixture matching neither — a bare `<slug>-directive.md`, the historical form — exits non-zero," and M8 itself says "No third form passes." The collision is not hypothetical in the corpus either: the file `docs/cycles/streamlining-directive.md` is both one of the 29 the spec counts as non-conforming and the exact name the green AC-CO-1 test writes.
Consequence: `bin/directive --name SLUG`, an invocation the preserved contract requires the cycle mode to support, produces a directive that the executor's first act must fail under J3 — the spec's own J3, whose whole point is that a lint failure returns the directive to the decision session. A Test Designer writing from §6 produces an AC-DT-06 fixture asserting `<slug>-directive.md` exits non-zero and an AC-DT-15 fixture asserting the same binary writes that name, and both are required to pass. This is the third consecutive cycle in which naming more of the absorbed contract has exposed a place where the absorbed tool and the specified tool disagree, and it is the first one this document's own text actively conceals, by quoting half of the criterion it cites.
Fix: One of three, and the choice is Dave's. (a) M8 becomes a three-pattern check, the third form licensed the same way the second is — `skills/directive-authoring.md`'s amended Naming sentence excepts "a reviewer-gated cycle directive ... per its stated convention," and the stated convention it defers to is AC-CO-1, which names both branches, so the license may already reach it (see O3). AC-DT-06's failing fixture then needs replacing with a genuinely unlicensed name, and §4's non-conforming count moves. (c) The cycle mode keeps `--name` and M8 keeps two patterns, with the spec stating explicitly that the cycle mode can emit a filename the lint rejects and naming who absorbs that. Whichever is chosen, §4 must quote AC-CO-1 whole.

## N1 — non-blocking
Claim: M8 does not decide whether a trailing `YYYYMMDD` with no time component is an ISO 8601 basic timestamp, one committed file sits on the line, and the spec's own non-conforming count depends on the answer.
Location: specs/directive-tooling.md §4 M8 row and the counts paragraph; §6 AC-DT-06, M8 clause.
Evidence: Verified by running. M8 admits `docs/cycles/<descriptor>-<timestamp>.md` "with the timestamp in ISO 8601 basic," and the governing sentence in `skills/directive-authoring.md` @ `83b60511` says only "the timestamp in ISO 8601 basic format." ISO 8601 basic admits a calendar date alone as well as a date-time. `docs/cycles/` holds exactly one file on that line: `metadata-scope-fix-20260823.md`. Counting it as conforming gives 61 timestamp-form and 28 non-conforming; counting it as non-conforming gives 60 and 29. The revision states 60/29 and, to its credit, states the classification rule it used and names the file — that disclosure was added this cycle and is why this is non-blocking rather than a silent number. AC-DT-06's M8 fixtures are a `<descriptor>-<timestamp>.md` pass, a `cycle-<N>-directive.md` pass, and a `<slug>-directive.md` fail; none of the three is the date-only case.
Consequence: Two implementers reading §6 write two different regexes, and the disagreement is invisible until a directive named with a bare date is either passed or failed at an executor's first act. The count of 29 is also not reproducible from the spec's own words without the parenthetical, and Core rule 13's changed-number discipline has nothing to attach to if the classification itself is undecided.
Fix: M8's element text states whether the time component is required. If it is, AC-DT-06 gains a date-only failing fixture and the count of 29 is anchored; if it is not, the count moves to 28 and the passing-fixture set gains the date-only case. Either resolution is one sentence and one fixture.

## N3 — non-blocking
Claim: The mode-scoping block's precedence clause resolves any conflict between this document's goals and the absorbed contract silently in the contract's favour, which suppresses exactly the class of finding that has driven the last three cycles.
Location: specs/directive-tooling.md §4, "Mode scoping", first bullet.
Evidence: Verified by reading. The clause reads: "Where a goal or criterion of this document would say otherwise, the preserved contract governs the cycle mode — 'preserved intact' is the dictated disposition, and this document is not free to narrow it by implication." It is unbounded: it applies to every goal and every criterion, including ones not yet written, and it names no obligation to surface the conflict it resolves. B1 is a live instance — M8 versus AC-CO-1's `--name` branch — and the clause as written disposes of it without anyone having to notice it, by ruling that AC-CO-1 wins in the cycle mode.
Consequence: The mechanism that produced cycle 2's B1, cycle 3's B1 and B2, and this cycle's B1 is contradiction between the specified tool and the absorbed one becoming visible. A blanket precedence rule makes future instances resolve quietly instead, and the document loses the property that has been generating its findings. It also weakens G0's stated benefit — one home for invariant text — by letting the two modes diverge silently in anything the contract touches.
Fix: The clause gains an obligation rather than losing its precedence: where a goal or criterion of this document conflicts with the preserved contract, the contract governs the cycle mode **and the conflict is stated in this document at the goal or criterion it reaches**, so precedence is a resolution on the record rather than a default. The three conflicts found so far — refusals (G4), writes (AC-DT-12), and filenames (B1) — are what the first pass of that obligation would enumerate.

taken and why the other was unavailable, and every companion citation in the

What sends this to `changes-required` is that the same scoping block also

half of AC-CO-1 this document does not quote. The cycle mode is required to write

and M8 says in terms that no third form passes. Three cycles running, the finding
has been the same: the absorbed tool does something the specified tool says it
does not. Refusals, then writes, now names. The pattern is strong enough that the
fix worth considering is not another scoping sentence but an obligation to
enumerate the contract whole — every AC-CO criterion, quoted in full, checked
against every goal and criterion here — before the migration is specified any
further.
