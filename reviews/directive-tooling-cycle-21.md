## B1 — blocking
Claim: §7's "Not accepted" set loses four of its seven members, and one of the three that survive is narrowed from a filesystem bound to a remote-write bound, so §7 no longer states the same prohibition AC-DT-12 states.
Location: specs/directive-tooling.md:469–471 (§7, "**Not accepted.** A requirement enforced that no governed file states (G6, AC-DT-13); a silent pass (G9); either tool on the write path to the remote (AC-DT-12)"). Prior text: `3e064f6`:3155–3200, the "Not accepted" paragraph.
Evidence: **Verified by running** (diff of the two §7 sections at `3e064f6` and `0b5a6d4e`) for the extension; **by reading** for the entailment. The prior set has seven members: (1) "Any lint claim about a judgment-only property"; (2) "Any exit 0 that does not state its bounds"; (3) "Any invariant text or required element hardcoded in a tool rather than read from committed text — that failure recreates the drift the tools exist to remove, in a place with less visibility than prose"; (4) "Any write from the lint, of any kind"; (5) "any write from the generator beyond the skeleton it was invoked to produce and, in the cycle mode, the directive file and bundle the preserved contract requires (AC-DT-12, AC-CO-11)"; (6) "Any refusal by either mode that turns on the *content* of a directive rather than on a precondition, which would put refusal in two places and make the generator a second gate"; (7) "Any lint enforcement of a requirement no governed file states (G6, AC-DT-13)". The rewrite carries (2), (7), and a **replacement** for (4)+(5) that is not the same claim: "either tool on the write path to the remote". Members (1), (3), and (6) are absent from the rewrite entirely — `grep -i 'judgment-only\|hardcod\|refus'` over §7 returns nothing for any of the three (*observed*, by running).
Consequence: Concrete, and it lands where a release gate reads. Fix: Restore the four members to §7's "Not accepted", each in one clause with the goal or criterion it points at: a lint claim about a judgment-only property (G7); invariant text or a required element hardcoded rather than read (G1, AC-DT-02); a refusal by either mode turning on directive content rather than on a precondition (G4); and the write bound as AC-DT-12 states it — any write from the lint of any kind, and any write from the generator beyond the skeleton and manifest, or in the cycle mode beyond what AC-CO-1 and AC-CO-7 require within AC-CO-11 — with the remote-write clause kept beside it rather than in place of it.
