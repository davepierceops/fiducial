## RW8-1 — non-blocking
Claim: Rule 7's tool-defect class and its counted classes both cover a success-shaped response whose read-back shows nothing landed, and the two give contradictory remedies.
Location: policies/remote-write-verification-policy.md, rule 7 — the "Never sent" and "Tool defect" bullets (lines 99–105) and the closing paragraph (lines 107–109); rule 2's qualifying list, second item (lines 32–33).
Evidence: Inferred by reading. Rule 2 lists "writes returning success but unconfirmable on read-back" as qualifying and counted. Rule 7 states that lost response and never sent are what rule 2 counts, defines never sent as "the call did not reach the remote; nothing landed", defines tool defect as "a well-formed call, and the tool did something other than what it reported", and gives tool defect a first-instance stop with no count. A well-formed call answered with success and read back as not landed is a tool that did something other than what it reported; whether the call reached the remote is not observable from the response. Rule 7 requires classification before any remedy, and this case classifies two ways. Rubric criterion 11 — an underspecified condition on which an escalation turns.
Consequence: An agent facing the most common connector-failure signature — success-shaped, not landed — either sends again and counts one (never sent) or stops on the first instance (tool defect). The readings differ by one retry, both end in a stop, and rule 6 governs the retry either way, so the harm is bounded; but the rule that exists to make classification precede remedy leaves its most frequent case unclassified.
Fix: Draw the boundary in rule 7 so the tool-defect class excludes the nothing-landed case — for instance, that a response whose read-back shows nothing landed is never sent and counted under rule 2, and that a tool defect is a well-formed call whose read-back shows something landed that differs from what the response reported (the rule 3 mismatch that rule 2's non-qualifying list, scoped to the agent's own malformed call, leaves to rule 7). Wording is the Editor's; only the boundary is needed.
