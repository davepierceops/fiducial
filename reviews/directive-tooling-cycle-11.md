## B1 — blocking
Claim: Scoping M3's search to the author region **as G11's manifest locates it** makes M3 undecidable on a directive carrying no manifest, and AC-DT-06's pre-existing M3 fixtures are such directives — so AC-DT-06 and AC-DT-10 now require opposite exit statuses for the same fixture.
Location: specs/directive-tooling.md §6 AC-DT-06, the M3 clause (`specs/directive-tooling.md:1494`); §6 AC-DT-10 (`:1605`); §4, "M3's search is scoped to the author region", third paragraph (`:703`); §7's accepted-risk list.
Evidence: Verified by reading, at the revision under review. AC-DT-06 as revised reads "a fixture with neither an exclusive assignment nor a sole-tree declaration **in that region** exits non-zero, a fixture carrying both **in that region** exits non-zero, and each of the two single-form fixtures exits 0 on that element", where "that region" is the disposition author region **as G11's manifest locates it** (*observed*). §6's own preamble states the test substrate is "fixture directives ... checked against a fixture repository", and this cycle's own added text states that the pre-existing M3 fixtures "are hand-written fixture directives carrying **no prompt region**" (*observed*). The revision then states, at §4 `:703`, that "What M3 does on a directive carrying **no** manifest is not stated here and this document does not decide it" (*observed*) — a bound this session wrote deliberately, because the disposition's "as the manifest locates it" presupposes a manifest and the disposition does not supply a fallback. AC-DT-10 reads, whole: "An element the lint cannot decide is reported unknown and exits non-zero; no undecidable element yields exit 0" (*observed*).
Consequence: Concretely, take AC-DT-06's single-form M3 fixture — a hand-written fixture directive stating exactly one exclusive assignment, no manifest. AC-DT-06 requires it to **exit 0** on M3. Under the new scoping M3 has no extent to search on it, so M3 is an element the lint cannot decide, and AC-DT-10 requires it to be reported unknown and to **exit non-zero**. Both are criteria in §6 and both are unconditional; an implementer cannot satisfy both, and the two are not distinguishable by any further reading — this is a contradiction between criteria, not an under-determination inside one. It reaches four of AC-DT-06's M3 fixtures (the two single-form ones, the neither-form one, and the prohibition one) and the sole-tree fixture with them. A second consequence sits in §7: the manifest dependency is a new residual class — every hand-written directive is now outside M3's decidable range — and §7's accepted-risk list names a hand-written class for **M8** only and does not carry this one, so a reader taking §7 as the risk statement gets a list that is complete for M8 and silent for M3. Note this is a reading of the document, not an observation of a tool: neither binary exists and no manifest was inspected (see *Not inspected*).
Fix: Three options, and choosing among them is Dave's. **(a) Require a manifest.** State that M3 as scoped applies to directives carrying a manifest, make every M3 fixture in AC-DT-06 a generated skeleton, and state at §7 that a hand-written directive is outside M3's range — which widens §7's existing hand-written defect class from M8 to M3 and should be stated as a widening, not absorbed. **(b) State a fallback.** M3 searches the author region where a manifest locates one, and the whole file otherwise; add the clause that this is safe, namely that a directive with no manifest carries no generator-supplied prompt region and therefore no form-naming text the author did not write — which is exactly the invariant the added AC-DT-06 text already asserts about the hand-written fixtures. This closes the contradiction without touching AC-DT-10 or §7. **(c) Make the manifest a required element.** Add it to the mechanically-checkable set under G6 with a governed source, which is the largest change and the only one that also reaches M1–M2 and M4–M8. Option (b) is the smallest and is the one this reviewer would propose, **clearly labelled as a proposal**; it is not taken here, because picking a disposition is not a reviewer's call.
Related: O4.
