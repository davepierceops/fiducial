Consequence: Inferred: a valid push can produce a false alarm, while the Codex command form supplies no automated remote-equality evidence. The retained manual verification obligation still applies; passing the hook cannot establish a successful remote write.

Add cases for both payload forms and a slash-containing branch against a real local bare origin. Reproduce through `.codex/hooks/codex-hook script '[]' push-readback` with JSON containing the stand-in repository's `cwd`, `hook_event_name: PostToolUse`, and the two inputs above.
