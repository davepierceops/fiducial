## DMP-4 — non-blocking
Claim: The widened `audience:` rule turns on the term "role document" and the policy never says what makes a document one, while enforcement decides it by a test the policy does not state.
Location: policies/document-metadata-policy.md:90-95 ("Values are the basename slug of any role document under `roles/` or `engagements/` (including `engagements/sre/`), plus three reserved values...")
Evidence: Verified by running. `bin/aimeta/repo.py:role_slugs` resolves the set by `_is_role_document`, whose docstring states the discriminator: a document whose own first heading is `# Role:` — "`engagements/working-with-dave.md` and `engagements/sre/README.md`, for example, are not." Applied at df35ea7 the rule yields fourteen slugs: the ten under `roles/` plus `assistant`, `cartographer`, `critic`, `implementer`. Every `audience:` value in the 51-file set resolves — seventeen distinct values, fourteen slugs plus `all-roles`, `all-decision-roles`, `human` — so the rule is satisfied in fact. The defect is that the policy states a rule an adopting repo cannot apply: nothing in it says a role document is one whose first heading reads `# Role:`, and `engagements/` contains four documents that are role documents and seven that are not, with no stated way to tell them apart. Criterion 11 — an underspecified condition the reader must resolve by inference.
Consequence: The policy is the source `bin/aimeta/scope.py` reads at runtime and the document an adopting project copies. A project standing up its own enforcement has the rule and not the test, so it either reads the methodology repo's code — which the policy elsewhere forbids relying on, durable policy not living only in tooling — or invents a discriminator that will not match. Inside this repo the practical risk is smaller and real: a new file at `engagements/<name>.md` silently becomes or fails to become a valid audience value depending on a heading nobody was told mattered.
Fix: State the test where the rule is. "A role document is one whose first heading is `# Role:`; `engagements/working-with-dave.md` and `engagements/sre/README.md` are not role documents." One sentence, and it is the sentence the code already carries as a comment.
