## F-1 — non-blocking
Claim: The "Naming" section licenses one of the two cycle-mode filenames the convention it defers to actually licenses, and never names where that convention is stated.
Location: `skills/directive-authoring.md:36-39` ("Naming").
Evidence: **Verified by running.** The section yields with "per its stated convention" and names no document. The convention is `docs/packages/package-a-spec.md` §3.6 AC-CO-1, implemented at `bin/cycle-open:58-67`: `--cycle N` writes `docs/cycles/cycle-<N>-directive.md`, `--name SLUG` writes `docs/cycles/<SLUG>-directive.md`, exactly one required (`bin/cycle-open:38-39`, `:155-157`; test surface `bin/tests/test_cycle_open.py:71`). The skill names the first branch only. `specs/directive-tooling.md:1755-1760` states the same defect independently and from the other side: "It names `cycle-<n>-directive.md` and then yields — 'per its stated convention' — to a convention it does not quote, and the convention it yields to names two branches, not one," which is why M8's patterns 2 and 3 anchor on AC-CO-1 directly rather than on this document.
Consequence: An author who runs `bin/cycle-open --name SLUG` — the documented, tested path — gets `docs/cycles/<slug>-directive.md`, a filename this document does not admit. Reading the governing document alone, they conclude the tool's output is non-conformant and either rename it (breaking AC-CO-1's destination contract, which is what bounds the name to a single path component) or avoid `--name` entirely. Neither is recoverable from the text they were told to read.
Fix: Name the convention the sentence defers to — `docs/packages/package-a-spec.md` §3.6 AC-CO-1 — and state both cycle-mode branches, or state neither and yield wholly.

## F-2 — non-blocking
Claim: The timestamp form fixes neither the timezone nor whether a `Z` suffix is permitted, and the corpus is split roughly evenly as a result.
Location: `skills/directive-authoring.md:36-38`.
Evidence: **Verified by running.** The sentence requires "ISO 8601 basic format with date and time components both present (as `20260820T161541`)". The example carries no zone designator and the text states no zone. Over `docs/cycles/`: 109 files match the timestamp form; **63 carry a trailing `Z`, 46 do not** (`ls docs/cycles/ | grep -E '[0-9]{8}T[0-9]{6}'`). Downstream, `specs/directive-tooling.md:1220` (M8) has had to admit both — "`YYYYMMDDThhmmss`, optionally `Z`-suffixed" — a looseness read into the source rather than off it. `docs/global-context/core.md` rule 14, which this section specialises, has the same silence and the same zone-free example.
Consequence: This is exactly the class the gate was asked to find: two careful authors reading the same sentence emit different filenames, and both are conformant. The cost lands on anything that matches these names mechanically — a lint pattern must carry an optional group it cannot justify from governed text, and any future rule that reads a time out of a filename (ordering two same-day directives, for instance) reads 46 of 109 names as local time of an unknown zone. The directive that dispatched this review had to state "UTC" itself because the governing document does not.
Fix: State the zone and the suffix in the same sentence — one clause, either "UTC, `Z`-suffixed" or "zone-naive, no suffix" — and let M8's optional group follow it rather than lead it.

## F-3 — non-blocking
Claim: The rule requires a *labelled* statement while delegating the label's fixed form to tooling that does not exist, and the second admitted form has never been written.
Location: `skills/directive-authoring.md:15-22`, third sentence ("...the label's fixed form is a tooling concern, not this document's").
Evidence: **Verified by running.** No governed file fixes the label form: `grep` for "label's fixed" / "labelled statement" across `specs/` and `bin/` returns only `specs/directive-tooling.md`, which itself defers — M3 at `:1215` states "the label's fixed **lexical form** is a **TRD** decision", and no directive-tooling TRD exists (`ls specs/` → `bin-land-trd.md`, `bin-land.md`, `directive-tooling.md`, `prd-template.md`, `trd-template.md`). Corpus: of 144 files in `docs/cycles/`, **27** carry a `WORKING TREE` label line and that is the **only** label form present (`grep -hoE '^[A-Z][A-Z ]*TREE[A-Z ]*'` → `27 WORKING TREE`, no other variant). Of the four files matching `sole.tree`, **all four are discussions of the rule** — the skill's own text, and three directive-tooling cycle directives dictating M3 — and **none is a sole-tree declaration in a disposition slot**. The second admitted form has zero instances.
Consequence: An author is required to emit a mechanically-distinguishable label against a form nothing states, so conformance is by imitation of the 27 existing files. An author whose directive needs the sole-tree form has neither a label nor a single worked example to imitate, and must invent wording that a future lint — whose whole contract per M3 is "label-presence and form-membership" — will then either match or fail. The failure is silent at authoring time and surfaces only when the lint lands.
Fix: Either fix the label form here (the rule requires it, so its form is not purely a tooling concern), or state the delegation's holder by path so the author knows where to look; and give the sole-tree form one canonical sentence, since no instance of it exists to copy.
