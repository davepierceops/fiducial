## CG-1 — blocking
Claim: The file declares an execution session and its body describes a decision session throughout, and it names two different recipients for the Cartographer's output in the same document.
Location: engagements/cartographer.md:9-10 ("The Cartographer runs as an execution session; its report — the question list and the rendered map — returns to the Assistant.") against :21 ("Dave asks; you dig; you answer with provenance"), :27-29 ("hand that to Dave — he decides whether to do it or ask the client"), and :30-31 ("Dave talks to people; you give him the questions worth asking, ranked").
Evidence: Verified by running. `git diff 8cdc0b9 287fa78 -- engagements/cartographer.md` changes the first sentence and nothing else; the four "How you work" bullets are byte-identical to the text reviewed at cycle 1, when the file declared a decision session. docs/global-context/core.md:41-43 defines an execution session as "an LLM agent session carrying out a directive against a working tree" and a decision session as the one that "triages, decides, and produces the artifacts that direct and record work." An interactive loop in which Dave asks, the agent answers, and the agent hands him a choice he decides in the moment is the decision-session shape Core names. The sister file was conformed differently and correctly: engagements/sre/system-discovery.md:9-10 now says the report "returns to the Assistant" and its step 3 makes the unknowns "the question list for Dave" — an artifact, not a conversation. This file keeps both the artifact framing (line 9) and the conversation framing (lines 21-31). Criterion 7 ("Session kind is explicit... says nothing only the other kind needs") and criterion 11.
Consequence: The `cartographer` bundle is 24 files and contains no decision-layer document — `all-decision-roles` selects nothing, which is known and excluded — so a Cartographer session running as declared has neither the register rules the "Dave asks; you dig; you answer" loop assumes nor a directive-shaped statement of what it is to produce. Worse, the file answers "who receives your output" twice and differently: line 9 says the Assistant, line 28 says Dave. An agent deciding where an unanswerable question goes has to guess, and the two paths have different latency and different people in them.
Fix: Conform the body to the declaration as system-discovery.md was conformed. "Dave asks; you dig; you answer" becomes the directive's question and the report's answer; "hand that to Dave — he decides" becomes "name the access or action that would answer it in the report"; the ranked question list is an output of the report, not a hand-off in conversation.
