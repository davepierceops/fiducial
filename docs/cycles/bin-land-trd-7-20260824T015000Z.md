### D7-N1 — accept, new decision (Dave, this session). Stated first; D7-B1 executes under it.
The divergence guard short-circuits. §3.2 step 5 states explicitly that the
guard stops at the first check that refuses; the second check does not run.
Rationale, for the document to carry in its own words: the tool refuses rather
than acting, so a refusal is cheap to retry, and reporting two simultaneous
refusal causes would require the report to describe a case that stopping makes
impossible.

This is what makes detail.branch_head's condition decidable on every path, which
N1 found it was not. Discharges N1.

### D7-B1 — accept, narrow the definition
Finding: §5.3's middle and right columns disagree for detail.branch_head; the
middle column's definition is true wherever a local <branch> exists, and the
absence rule resolves the disagreement toward the wide reading, so the document
still specifies branch_head on FM-4 through FM-9 and the success path.
Resolution: narrow the middle column's definition to match the right column —
the fact is the SHA read by the check that refused, not by a check that ran.
Do not widen the right column. The narrow scope was ruled correct on the merits
by the cycle-6 reviewer, by probe, and accepted by Dave. Under D7-N1 the
condition is now well-formed on every path. Fix pointer: B1 Fix field.

### D7-N2 — accept, floor becomes ceiling. Reverses D-O1 (cycle 3) and the floor half of D5-N1 (cycle 5).
Finding: the floor rule makes over-claiming untestable — nothing can catch an
implementation emitting a key on a path where it should not appear — and the
under-specification that motivated the floor is fixed.
Resolution: §5.3's table states exactly which keys appear on each path. A key
present in the accumulated facts but outside its stated paths is not emitted.
The rule stays one rule, stated once, governing contract fields and detail keys
alike — D5-N1's structure survives; only its direction reverses. State the
reversal's rationale in the document's own words, not as a changelog.

Dave's reasoning, for the record: the floor was scaffolding for a table that
could not yet be trusted, cycle 6 verified the table mechanically in both
directions and swept the document for anything contradicting it, and the failure
mode of a ceiling is the recoverable one — a missing row is a one-line fix a
test catches, where over-reporting under a floor is caught by nothing. Fix
pointer: N2 Fix field.
