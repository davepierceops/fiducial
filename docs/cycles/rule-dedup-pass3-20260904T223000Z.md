STEP 2 — adjudication and sweep. Fill the verdict column of every candidate pair with exactly one of: same, same-with-divergence, different. Two rows are the SAME RULE when they bind the same party to the same obligation under the same condition, however worded; a binds of all covers every party, and a session-kind binds (decision, execution) covers the roles that run as that kind. They are SAME-WITH-DIVERGENCE when they are the same rule but the obligation, party, condition, or exception differs in a way an agent could act on — stricter, looser, different trigger, different party. Otherwise DIFFERENT. A definition clusters only with another definition of the same term. Then the sweep the shortlist cannot do — restatements share no words: for each verb, read the id and rule columns of that verb's rows whole (for require, one binds value at a time), and record any same or same-with-divergence pair the shortlist did not propose by appending it to the candidates table with jaccard and ratio left as — and a note column value of swept.
