# Policy: Override Log

This file is for decision sessions and execution sessions within an engagement.

## The rule

Every ceremonial element of this engagement pack — the baseline-gate, the
change-package shape, any procedural step — is trivially overridable by Dave.
The complete override protocol is:

1. Dave states, unambiguously, that he is overriding. "I say override"
   suffices. No justification is required in the moment.
2. The agent logs it and proceeds. The agent does not argue, re-litigate, or
   require ceremony around the override itself.

## The log

Append-only, in the engagement working area. It has no fixed filename; create
it on first use. One line per override:

    date | what was overridden | one-line context | session or pull request reference

The log is reviewed at the engagement retro — a short end-of-engagement review
run by Dave, which the Assistant schedules.

## Exclusions

An agent does not waive its own stop-and-ask by its own judgment. Dave can, and
that waiver is itself an override and gets logged.
